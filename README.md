## 🚀 Principais projetos

### 🌱 Eco Raiz 360 — Inteligência Agroambiental

**Integração de dados para analisar a cadeia da soja e apoiar a identificação de oportunidades agroambientais.**

Projeto desenvolvido em equipe no bootcamp de Análise de Dados da **Generation Brasil**, pela equipe **Raiz Inteligente**.

O Eco360 reúne dados de produção de soja, clima, uso do solo e emissões no Centro-Oeste e Sul do Brasil, abrangendo **1.661 municípios**, com dados de **2019 a 2024**.

**O que desenvolvemos:**

- Integração de bases de diferentes fontes.
- Pipeline de extração, limpeza, padronização e carga de dados.
- Modelagem de dados em MySQL.
- Dashboard em Power BI para análise territorial.
- Índice de Oportunidade Agroambiental — **IOA**.
- Documentação das etapas e decisões do projeto.

**Minha contribuição:** limpeza e integração dos dados, pipeline, medidas DAX, documentação e apresentação dos resultados.

### ♻️ Visão Computacional — Reconhecimento de Resíduos Recicláveis

**Classificação de imagens de resíduos com Machine Learning.**

Projeto desenvolvido pela **Equipe 2 do bootcamp de Machine Learning da Atlântico Avanti — edição 2026.1**, utilizando o dataset *Recyclable and Household Waste Classification*.

**Etapas desenvolvidas pela equipe:**

- Verificação da integridade dos arquivos e da qualidade das imagens.
- Análise da distribuição das classes e identificação de duplicatas.
- Separação dos dados para treinamento.
- Treinamento de modelos para classificação de imagens.
- Análise dos resultados e apresentação das conclusões.

O repositório reúne o notebook e as apresentações das etapas do projeto.
